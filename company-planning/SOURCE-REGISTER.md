## Record claims once

In commercial/00-evidence-baseline.md keep: ID, assertion, fact/decision/hypothesis/estimate status, source path or URL, version/date/section, short exact quotation where required, access date, owner, conflict and validation method. Add assumption IDs for financial inputs. Other artifacts link to IDs rather than maintain competing facts.

Distinguish user statements, document claims, observed tests and external benchmarks. Preserve this chain: underlying evidence → baseline ID → recommendation → financial assumption → execution task → derived deck/summary.
