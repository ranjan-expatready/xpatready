## Major (new)

### N-1. *All files I may see* in shape 1 has no single rule. Under the default seeding it gives a Case Officer the firm-wide deadline list that SA-06 reserves for the firm-wide report key.

**Where:**
- The §1 table row "Minder watches" (doc L52): "part of the case, under the case keys below; the firm-wide list is a dashboard … (AG-14-17), under the report keys".
- L65: "a Case Officer who picks *all files I may see* gets the answer over the files their keys open".
- The §4 Case Officer row (L229): "every case by default … their own figures only".
- Rule 1 of shape 1 (L109–L110).

**What is wrong.**
- **The two rules give different answers.** The see-all case keys are seeded on all six starter roles (SA-06 L1307). So "the files their keys open" means every file of the firm for a default Case Officer. But SA-06 §3.3 says: "**Dashboards are not record visibility.** 'See all' opens records; it does not give firm-wide reporting. … `agent/report:view.all` (firm-wide dashboards) is held by **Owner, Admin and Case Manager only**" (L275). Shape 1 over all files is, in substance, AG-14-17's "upcoming deadline horizon and list", which is a report. The document never says which key decides. Read by the case keys, the expert widens what AG-14 BR-2 says a filter can "never widen", against IMP-20 rule 3.
- **The example does not test the default.** The worked example avoids the question: the Firm B officer's copied role has no see-all key (L319).
- **The Firm assistant reached a different answer on the same list.** Its row (proposals L76) recommends that a list of *other* file owners' slipping deadlines "follows the escalation part": with escalation off, the viewer gets only their own files. Under this document, an Owner or Case Manager in a firm under five staff, with escalation off, picking *all files I may see* would get every colleague's overdue deadlines. That is the staff-facing escalation the firm switched off (AG-11-49).

**Fix.**
- **Write the rule (Proposal):** *my files* is decided by the case keys over the asker's own and case-team files. *All files I may see* additionally needs `agent/report:view.all`, as for AG-14-17. Without that key the menu does not offer *all files*.
- **Follow the escalation part:** with escalation off, *all files* lists only overdue and unassigned items the product already raises to that viewer (AG-11-55), the same rule as the Firm assistant's row L76.
- **Make §4 agree:** state the result in the Case Officer row.
- **Record it:** add a §9 gap and one line to §11 decision 2 or decision 8.
