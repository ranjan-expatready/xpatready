## 4. New findings

### Major

**N-1. README rule 11 lets a module file override a Founder Decisions Log entry, against rule 2 and IMP-31; this document applies it to FD-21.**

- **Where:** doc L318, L338, GI-23 (L407); README L21 (rule 11) against README L9 (rule 2) and `ws2-improvements.md` L327 (IMP-31).
- **What is wrong.** Rule 11 says the newer module file wins over "Doc 1–4 or the decisions log". Applied here, AG-05 v1.9 §13 "wins" over FD-21. FD-21 sets a signer-assurance floor that amendment A22-5 makes "the platform minimum, applied everywhere" (FDL L106). Whether FD-21 counts as ratified is itself unclear: FDL L46 says FD-20 and FD-21 are "recorded here for ratification only". Either way, a module file cannot settle it: rule 2 and IMP-31 reserve it to the founder. The document's outcome is safe (S7a conditional, GI-23 to the founder), but the reason written into it is the wrong precedent for the other six documents.
- **Fix.**
  - For the Lead: amend rule 11 to "newer module files win over Doc 1–4; a conflict with an FD-n or the decisions log is recorded and goes to the founder".
  - In the document: replace "under README rule 11 the newer AG-05 wins" with "the conflict is open and goes to the founder (GI-23); until then the passcode is listed as conditional". Note that AG-05 L757 defers "OTP-to-phone", while FD-21's default channel is email.

### Minor

- **N-2. The `sourceItemRef` rule is not stated** (doc L98 step 4, L121 2.2 step 5, Day 0.4 L276, Day 1.6 L291).
  - The persona creates two tasks (P1 *Run an assessment*, P4 *Re-run the assessment*).

  - *Fix:* one clause in step 4 ("a plain reference to the lead; never `sourceItemRef`") and one never-row citing AG-13 L481.
- **N-3. The trigger gaps are overstated, including in my own S2f M-9 and M-11.**

So a generic `CREATED` on the Assessment, or `STATUS_CHANGED` on a Booking, may already be able to start a run.
  - What is missing is the first-class *named* events and any statement that AG-03's `Assessment` and AG-04's `Booking` are covered by the generic bus. Whether they are is Unknown.
  - Affected text:
