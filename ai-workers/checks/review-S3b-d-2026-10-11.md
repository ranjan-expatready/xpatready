**N-16. AW-2-11 contradicts the `Delegation` entity's own uniqueness rule in AW-01.**
- *Where:*
  - AW-02 AW-2-11 L349;
  - §6 delegation guard L483 ("no active delegation for the same person, persona and role");
  - §7 `Delegation` L525 ("AW-01 L569; platform values");
  - §9 L729 ("One person holds Support and Account manager → two delegations").
- *Evidence:*
  - AW-01 L569, the one home of `Delegation`, says: "At most one ACTIVE or PAUSED per (`firm_id`, `delegatingUserId`, `personaKey`)."
  - On the platform, `firm_id` is empty and both the Support and the Account manager delegations use `personaKey` SUPPORT_ACCOUNT (AW-02 L525).
  - AW-2-11 requires "two delegations with separate subsets" for one person who holds both roles. Built to AW-01, the second delegation is refused.
  - AW-02 §7 says entities are "defined in AW-01 §7 … this module adds only the platform values" (L523), so AW-01 wins and AW-2-11 cannot be met.
  - §13 Q12 (L989) lists field-name alignment but not this rule.
- *Fix:*
  - The AW-01 maker adds `delegatingRole` to L569's uniqueness rule.
  - Until then, AW-02 Q12 names this conflict and AW-2-11 points to it.
  - The Lead's integration pass checks it.

**N-17. The Support Triager can propose a plan change with no second person, against AIW-D59's own words.**
- *Where:*
  - AW-2-65 L417 (the fix menu "*Extends* SA-4-36, SA-4-19, SA-4-54, SA-4-28");
  - AW2-D12 L174;
  - AW-2-72 L424;
  - US-21 L632;
  - US-25 L653.
- *Evidence:*
  - AIW-D59 (decisions.md L63): "A second Expat Ready person confirms **any account or plan change the Support assistant proposes**". The Support Triager (W-22) is the Support assistant.
  - AW-2-65 has a rule "map the code to a fix from a fixed menu and to the role that may do it". The menu reaches SA-4-28, the plan change (SU §2.1 step 5, L109: "a plan change the Owner does in the billing screen (SA4-D23) or Super Admin 'with a reason' (SA-4-28)").
  - AW-2-72 applies SA-4-89 only to a change "that carries the reference of a note the Support and account assistant proposed (AW-2-71)". A plan change made from the Triager's fix line carries no note, so it is "a person's change … as today", with no second person (AW-2-72; §9 L763).
  - AW2-D12 and the Lead's call (plan L88) exempt only re-running a notification and sending an update-card link, as "changes no account". A plan change is an account change.
  - SU L109 itself routes this fix to the note ("prepared by the account manager (§2.2 step 6)"). AW-2-65 dropped that routing, so content was lost in the rewrite.
- *Fix:*
  - AW-2-65 states that when the mapped fix is any change SA-4-89 lists (plan, billing period, discount, cancellation or its undo), the fix line reads only *ask the account manager for a change note (AW-2-71)*. The menu never names a direct account change.
  - AW2-D12 says so.
