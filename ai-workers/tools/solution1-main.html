Pathway Setup to Form Filling

Set up each combination once. Ask each fact once. Fill every form and portal screen from the same facts.

1The blueprint

  1. One row per combination. A person enters the base forms and documents. The AI drafts the rest from the official checklist, the forms and the guide. Nothing is published without a second person.
  2. One library for every row. A box with a known label in the same context matches by rule. The AI proposes only for new labels. Portal screens go the same way: the extension captures each screen's fields, the AI matches them, a person checks.
  3. Everything the case needs, versioned. Question sets, conditional rules, form and portal maps, screen layouts, each item with its own version inside a pack version. A case pins the pack version until a person adopts a new one.
  4. Facts live once. Every screen reads and writes the same store. A newer verified value replaces an older one with history; a contradiction waits for a person.
  5. PQR before the combination is known. One PQR per country, in blocks that unfold from what the prospect wants.
  6. One shared duplicate check on lead capture, add client and import. It asks; it never merges silently.
  7. SQR per person in the client portal: only facts not already known, only blocks the rules switch on.
  8. The agent enters each fact in one place. Form screens never take typing; a fix on the fact re-fills every form.
  9. Forms are renderings. Rules fill each applicant's copy. The AI only cross-checks. Barcode forms get their data written; a person clicks Validate. The licensed reviewer approves and submits; the applicant signs where a form requires it (Unconfirmed: no counsel, AIW-D94).
  10. Change without breakage. A new edition re-matches changed boxes only; rows are untouched.

3Lead to case

  • One person, one record. A returning client starts with confirmed facts; only "still true?" items are asked again (address, job, travel). Identity facts are never re-asked unless a new document differs.
  • Family is one case. Each person has a role, own questionnaire, own form copies; shared answers and shared documents are given once.
  • Corporate is one case per assessment, occupation and location. The employer is the subject; each worker gets an individual case linked to it.

Sources: AG-02 decisions §3.2 (soft "same person?" note, never merge at capture, one shared check); AG-7-70, AG-7-73, AG7-D3; AG-15 AG17-D66 (staff answer on behalf); SA-1B-70, 73–76; D184, D185.
