## A. Founder questions, answered

### 1. The channel question — "PDF online and a signed PDF upload, what is that?"
**[verified]** The taxonomy is coherent and server-derived, not an inconsistency:
- Per **form line** (combination → Forms table → "Filed as"): `PDF upload` · `Online` · `Signed PDF upload`. Each line is exactly one channel.
- Signature is **derived**, never stored: Online → "The client signs the declaration in the portal"; Signed PDF upload → "Printed, signed by hand, scanned and uploaded"; PDF upload → "No signature in the file" (shown next to the select).
- Per **combination**: one portal picker (IRCC Portal, APR Portal, Representative PR Portal, LMIA Online — labelled "Sample portals until the immigration expert confirms"). Header "Filing: PDF only" updates live — flipping IMM 1295 to Online changed it to **"Mixed: online and PDF"** (verified in browser).
- So "online + upload of the signed PDF" already exists as a **composition**: mark some forms Online and others Signed PDF upload → the detail wording becomes "Online + signed PDF uploads" (engine/channels.ts `filingMethod`). No fourth option needed.
- Sources tab "Drafting reads" (PDF first / Online screens only) is a **different axis** — which input the AI reads — and correctly lives on the form, applying wherever it's used.

**[validate]** The three per-form labels rely on the signature hint beside them; a first-time reader may still ask "is plain PDF unsigned?" Suggest a one-line tooltip per option (wording ready below). Minor.

### 2. Manual vs AI for reusable fields
**[verified]** P-15/P-11 are implemented: the shared library is AI-proposal-first; "Add a field" exists as manual secondary; server guards enforce field-key shape (`area.name`) and require a meaning sentence; the /new path builder has inline duplicate checks with "exists: choose it" hints — the same BR-6 pattern applies to library adds. Manual additions are proposals needing a second person's approval, so duplication risk is managed by process, not by forbidding manual entry. **Recommendation: keep both; manual stays the escape hatch with the same equivalent-check.**

It is workspace-level, not per-combination; it does clear every canonical field so a fresh AI run starts from blank. **[decision]** The founder asked for a per-combination reset — that does not exist; propose backlog item or confirm workspace reset suffices for the demo story.
