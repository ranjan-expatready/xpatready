# C5.5 — release refused without a passing signed answer-key test (G2)

PR #568: a real release is refused at Submit, Approve and the shared release while a form map or eligibility rule set that is new or changed since the last release, or already has an answer key, lacks a passing key signed by the immigration expert; the refusal names each item, and Review and release lists them with **Fix on Tests** and an "Answer-key tests" block. Only the demo workspace releases Sample content, as a Demo release (unsigned or untested items warn there; a failing key still refuses). Tests run at Submit and again at release; the release records the keys it rests on. Checks: `tests/check_g2_answer_key_gate.ts`, `tests/check_g2_answer_key_gate_firm.ts` (a non-demo workspace), `tests/check_g2_answer_key_gate_browser.cjs`.
