## What slice 1 does
* **Form finder API** (`api/src/finder.ts`): one run per combination, six tracked steps — find the application page (a person's choice, the page used before, a sure rules match, else AI picks with a checker round) → read it and the guide it links (rules list every printed form number, US$0) → AI lists the forms (draft round) → a checker round reads the same pages blind (P-121) → each form from the library, else downloaded from canada.ca (its own page and PDF, identity read from the file, checksum, duplicates) → attached with no confirm step, "Picked by AI · Sample" (`AI_FOUND`).
* **Rules on both AI rounds**: a number not printed on the pages, or a quote not on the page, is dropped and listed; both rounds agree → attached; disagreement or one round only → "Decide" (not attached); separate application / not needed → listed, never attached; the guide itself named in form style ("IMM 5256") is recognised.
* **Modes**: live (guarded route only: stub pass, ledger, run cap; cost stated in the plan), replay (the newest saved real run of exactly these pages and prompt, US$0), rules (lists, attaches nothing).
* **Library API** (`api/src/form-library.ts`, `form-uses.ts`): one lean list with type · used-by · status filters and search; where used; delete only unused and never released, retire only released and unused, restore — all through the P-116 lifecycle (a second person approves; `lifecycle.ts` kind `library_form`); "check canada.ca" for a form; attach by hand, remove (stays in the library), Undo of the last forms-list change (finder attach included), refused when a line changed since.
* **Official downloads** (M2, M3, Q-L1): `OfficialDownload` rows carry the manifest's evidence; the intake, the library list, field-map drafting (live included), edition impact review and the AI guard (`p2/guard.ts` contract `official-download/v1`, `read_form.py`) admit them; a hand upload equal to canada.ca's PDF counts as one (no second person); any other upload is held as before (P-80).
* **M6**: the finder compares library forms with canada.ca too (US$0): same file → checked date only; same printed edition, other file → library edition stays, form marked "Newer file on canada.ca"; newer edition → held for today's edition impact review.
* **canada.ca port** (`engine/canada.ts` pure parsers, `api/src/canada.ts` live/fixture adapters): official hosts only, on-host redirects (≤ 3), 20 s / 60 s, ≤ 25 MB, PDF magic; recorded copies by default (CI, tests, demo), live only with `STUDIO_CANADA=live` on the Mac.

## Choices (small, technical)
* Finder steps are `DraftingJob` rows with status `WAITING` until started, so the field-map worker (`ai.ts`) never picks them up; a server restart ends an open run "Find again".
