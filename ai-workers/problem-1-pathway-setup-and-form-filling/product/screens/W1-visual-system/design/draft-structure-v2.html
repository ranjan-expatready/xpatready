0 · What the founder asked, and where this board agrees or pushes back

Founder, 27 Oct (condensed): "When we click Add pathway, a row pops up at the bottom ('New pathway in Retail' + Add); it is very cumbersome. I want one pop-up where the person enters Pathway type, Pathway, Program, Category, Sub-category one by one, the way we used to create it, and then the tree and the cards fill in. Also the tree is vertically scattered; it looks too much. Should we have one-liners and a card layout? Think about it; do not follow me blindly."
This board's answer
  • Agree: one dialog (§1), five fields top-down, each picks an existing name or types a new one; the old path builder's checks (C1.2) come back, now with Pathway and "Cases may be opened from". The inline add row and every ghost "+ Add …" row go: one way to add. [F P-125]
  • Push back, small: it is one dialog, not five steps (a 5-step wizard breaks EXPERIENCE §3 "≤3 steps" and hides the context above each choice); Pathway type is a two-button switch, not a box you type into (it is a fixed value, S1 §3); Add may stop at a Program so a new Program can exist before its categories.
  • Agree: the tree is too much. Recommended A (§2): Pathway cards, then the chosen Pathway's Programs as sections, one line per combination. Two visible levels instead of five indents; no add rows; nothing lost (§3). This replaces this morning's Cards / Tree switch, so it is founder question Q1. [CONFLICT] P-115 (27 Oct pick C)

2 · The page — three layouts, each with the 5 and the 50 combinations

Same controls in all three: Pathway type tabs with counts, Find a name in every pathway, Expand / Collapse all, the counts line, the details panel (unchanged), the Sample footnote. None has a "+ Add …" row any more: adding is the dialog. Measured heights are in the dark-blue badges; the comparison is in 2d.

★ Recommended A · Pathway cards → the Pathway's Programs as sections → one line per combination

No tree and no switch. Pathway cards (stripe, counts by status, need you) choose what shows; each Program is a section card with its count and "+ Add category"; each combination is one line: Category › Sub-category (Trail identity, VS-3), status, cases may be opened from, used by, and a ⋯ menu (Open details, Rename, Cases may be opened from, Move up / down, Add sub-category, Remove or retire). Clicking a line, a section title or a card's name opens the same details panel as today. The page opens on the Pathway the person last chose (the first one on a first visit); “All pathways” shows every band. A Program with no categories shows as an empty section; a Pathway with no programs as a band with "No programs yet".
