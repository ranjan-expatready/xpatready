1. Option A · Numbered outline Recommended

Each Pathway is one quiet block with its stripe; each Program is a white block inside it, indented one step; categories and sub-categories are rows inside the Program block, indented one more step each and numbered. Status, where cases may be opened and Used by sit in fixed columns on the right, so every level lines up. Edit and Delete are written on every row. The List view is one flat table: one line per combination, the full trail written out.

1c · Edit, Delete, Retire: the actions on every row

Edit on a Program opens the existing side panel with the name ready to change: checks under the field as you type (exact twin, "did you mean"), order (Move up / Move down), where it is used and history. Pathway type cannot be edited (it is the tab, fixed). F P-118 checksF P-116 reorder

Delete on an unused line: an in-page confirm says what goes and that a second person approves on To review (as built). After it, the row reads Deletion waiting and Delete turns into Withdraw. Delete on a Pathway or Program deletes the whole branch only when nothing in it is used, listing every name GAP: branch delete, Lead (recommend: allowed when the whole branch is unused)

Delete that cannot run stays visible, greyed, and says why on hover or focus: Visitor visa has a setup draft, so neither it nor Visitors nor Temporary residence can be deleted. F P-116 "say why"

What a retire looks like Sample state: nothing in the sample is released yet; shown as if Express Entry stream and Start-up visa had been released; Start-up visa already retired. Each Pathway is a heading band; its Programs are cards in a three-column grid; each card lists its categories and sub-categories, numbered, with small status chips and Edit / Delete icons.
