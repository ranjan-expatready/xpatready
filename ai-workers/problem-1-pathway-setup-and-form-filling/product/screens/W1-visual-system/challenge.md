### What is sound
- Option A reuses the built bands and sections. The Edit panel already exists (name with checks, cases may be opened from, Move up / down, where used, history), as do Withdraw and the lifecycle API. No new endpoint is needed for Tree, List, Edit, Retire, Restore or Withdraw.
- Show retired is already in the read: `GET /structure?retired=1` returns retired names, and each combination carries `retired`. QA-48's missing view is closed in the page alone.
- One Add with the built pop-up: `POST /structure/path` is tested against the server (`check_w1_structure_path.ts`, 28 steps), and its prefill already takes Pathway and Program keys.
- Add combination in place on Immigration programs reuses the pop-up and `POST /structure/path`, then refreshes the catalogue. A new name is listed as Not started; no setup starts (P-125).
- Filter state belongs in the URL (P-115). The view choice is kept per person, like the Pathway choice today (`xr-structure-pathway:<actor>`).
- Immigration fit: numbers are display positions, not IRCC codes, and the tooltip says so. The same name under two Pathways (Retail "Temporary residence" and Corporate "Temporary residence") stays distinct through the type tabs and the full trail (QA-51).
