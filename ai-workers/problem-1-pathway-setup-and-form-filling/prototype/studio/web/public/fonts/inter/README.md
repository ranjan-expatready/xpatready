# Inter (self-hosted)

Provenance (§8b W0 D4):

- **Source package:** [`@fontsource-variable/inter`](https://www.npmjs.com/package/@fontsource-variable/inter) — **exact version `5.2.8`** (npm dist-tag `latest` at extraction time, 2026-07-17).
- **Obtained via:** `npm pack @fontsource-variable/inter` in a scratch directory (NOT added as a project dependency — no entry in any `package.json`), then extracted and hand-copied. This mirrors the §8a W10 Noto-font precedent in `apps/worker` (commit `3cbc95b`): vendor the static font asset, skip the runtime dependency.
- **Files copied**, from the package's `files/` directory, `wght.css` manifest (variable weight axis, upright style only — no italic, no `opsz` axis file):
  - `inter-latin-wght-normal.woff2` (48,256 bytes) — `unicode-range: U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0304,U+0308,U+0329,U+2000-206F,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD`
  - `inter-latin-ext-wght-normal.woff2` (85,068 bytes) — `unicode-range: U+0100-02BA,U+02BD-02C5,U+02C7-02CC,U+02CE-02D7,U+02DD-02FF,U+0304,U+0308,U+0329,U+1D00-1DBF,U+1E00-1E9F,U+1EF2-1EFF,U+2020,U+20A0-20AB,U+20AD-20C0,U+2113,U+2C60-2C7F,U+A720-A7FF`
- **Why latin + latin-ext (and not the other subsets the package ships — cyrillic, greek, vietnamese):** ERv2 ships en / fr-CA (§8a W7 i18n). `latin` covers ASCII/en; `latin-ext` covers the Latin diacritics fr-CA needs (é, è, ç, à, œ, …) plus other Latin-script European accents. Cyrillic/Greek/Vietnamese subsets are not required by any currently-shipped locale and are deliberately NOT copied — keeps the self-hosted asset footprint minimal. Adding a locale later that needs another subset is a one-line addition to this directory + the `@font-face` block, not a rebuild of this mechanism.
- **Axis:** `wght` only (weight 100–900, upright/normal style). The package also ships an `opsz` (optical size) axis file and italic variants of both — neither is used; the app has no italic/optical-size design requirement this wave.
- **License:** `OFL.txt` in this directory is the package's unmodified `LICENSE` file (SIL Open Font License 1.1). Per the OFL, the font may be embedded, redistributed, and modified provided the license/copyright notice travels with it — hence this file's presence alongside the woff2s. Inter carries no Reserved Font Name, so no renaming obligation applies (same disposition as the Noto fonts vendored in `apps/worker`, §8a W10).
- **Not copied:** the package's CSS (`index.css`, `wght.css`, etc.), SCSS mixins, `metadata.json`, `unicode.json`, `README.md`, `CHANGELOG.md` — the `@font-face` rules are hand-authored in `apps/web/src/styles/tokens.css` (unicode-range values copied verbatim from `wght.css`, see above), so none of the package's own CSS/tooling files are needed at runtime.
