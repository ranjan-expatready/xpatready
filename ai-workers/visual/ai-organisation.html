0. The idea in five lines

  1. Expat Ready is built for people: every action has a permission, every automated message has a template or an approval (a person's own hand-written message is a normal send, AG-11 v1.11 §3.3), every rule comes from a published Country Pack (the rulebook for a destination country; FD-22, Founder Decisions Log v1.5).
  2. An AI persona is an assistant to one of those people. It does the same work, through the same product, under that person's own permissions, and it stops where a named person approves (AIW-D13, AIW-D26).
  3. There is no AI user. FD-16 (Founder Decisions Log v1.5): no AI principal in the identity spine, no autonomous permissions, and Marketing may say 'AI-assisted'; it may not say the AI decides. The team's own Product Vision says the same in four words: AI assists; humans decide (Product Vision v1.0 (team), section 00).
  4. Five personas serve the firm; two serve Expat Ready's own team. Together they carry 27 of the 28 workers in the catalogue. The 28th, the free Deadline watch (W-02), is the product's own deadline watching, with no AI, on every plan: it is drawn beside every file owner as the free hook (the free thing that gets a firm in the door), never as an AI persona and never described as AI. The wedge, the first paid AI duty, stays the File Builder. Decided 11 Oct 2026, AIW-D37; corrects AIW-D17.
  5. Nothing is built yet. Every "hours saved" figure is an Assumption until the pilot (AIW-A6); every price is an Assumption until the Step 5 conversations; no pilot runs on real client files until counsel has read the counsel pack (decided 11 Oct 2026, AIW-D64).

1.5 Four facts that hold for every persona

  • Works under one named person's delegation (IMP-1, Proposal; assumptions AIW-A2): the record says which worker, for which person, which subset of that person's permissions, on which files, from when until when. Any named staff member may have an assistant (a case officer, a bookkeeper); the licence sits with the approver (AIW-D13 read as a named person: decided 11 Oct 2026, AIW-D36).   • Is a recipe, not a model with hands (IMP-10, Proposal): the product's own automation engine runs it as an ordered list of product actions; the AI inside proposes values, and a model never selects which action runs (IMP-10, resting on AG-11 v1.11 AG-11-94: models have no tool access).

2.1 Case assistant

assistant to the Case Officer · catalogue W-25 "AI Case Processor", with three duties added (W-05, W-06, W-13; see "Bundles")

In plain wordsThe case officer's own assistant. From the moment the retainer is signed it chases the client for documents, reads what arrives, fills in the questionnaire with values that each show their source, drafts the letters and forms, and hands the officer a file marked "ready for review". The officer and then the reviewer decide; the assistant never files anything with the government.

Job
Prepares every case officer's files from retainer signed to ready for review, reads what arrives, drafts what goes out, and hands the officer and the reviewer a file where every value shows its source.
What it does
  1. Builds the file from the moment the retainer is signed (the product's event envelope.signed) to a readiness report: chases documents, reads them, proposes questionnaire values, cross-checks facts, keeps the checklist current (W-01; AG-07 v2.7 §3.4, AG-08 v1.7 §3.8, AG-09 v1.8 §3.8–3.9; recipes AG-11 v1.11 §3.5).   2. Checks each upload on arrival and drafts the accept or reject reason in the client's language (W-04; AG-09 v1.8 §3.8–3.9; Doc4 v1.3 CP-4 §3.5).
  3. Files every inbound email and WhatsApp on the right record and hands attachments to the Reader for typing (W-07; AG-10 v1.9 §3.2, §3.5; IMP-12).
  4. When a government letter arrives, proposes the milestone, the deadline, the task, a client notice and a response plan (W-03; AG-07 v2.7 §3.7).
  5. Drafts the firm's free-text client words in the client's language, and the French of non-legal template text (W-08; AG-10 v1.9 §3.3; AG-12 v1.2 §3.6; SA-05 v2.2 §3.5).
  6. Assembles the form set and fills every box from verified values only, flags what is unmapped or unverified, routes four-eyes (a second person checks the form before it goes out) (W-05; AG-07 v2.7 §3.5; SA-01B v1.2 §3.5). AI stays out of the fill path by rule (SA1B-D16; IMP-25).
  7. Drafts letters of explanation, submission letters and procedural-fairness responses (the reply to a letter in which the government states its concerns before deciding) with a "facts used" footer (W-06; AG-10-15; SA-01B v1.2 §3.9).
  8. On a corporate file (an LMIA, the federal approval an employer needs before hiring a foreign worker): reads advertising proof, builds the candidate log from staff entries, proposes the duties comparison, drafts the recruitment report and prepares the inspection-pack list (W-13; AG-17 v0.5 §3.4–3.8). Never screens or ranks candidates (FD-7).
  9. Writes an internal pickup summary per file, a leaver's handover list and each person's ranked day (W-17; AG-13 v1.12 §3.4; AG-07 v2.7 §3.8).

8. Glossary (plain words; the product's own terms where they exist)

AI personaThis document's unit: an assistant to one human role, made of several catalogue workers (duties), working under that role's delegation. Not a user (FD-16).
AI WorkerThe workstream's name for one job-shaped bundle of Doers and recipes that does a whole job a person does today, on behalf of a named person, stopping at a human sign-off (ws2-improvements.md glossary). The catalogue has 28 (W-01 to W-28); since 11 Oct 2026 one of them, W-02, is the product's own deadline watching (AIW-D37).
DoerOne of the product's own single-job tools: the Mailer sends, the Reader reads documents, the Minder watches dates, the Reminder sends nudges (two tools: FD-8 amended, decided 11 Oct 2026, AIW-D51), the Filler fills forms (AG-11 v1.11 §3.0, §3.3). Four are AI Doers: Reader, Sorter, Writer, Checker (AG11-D4; AG-11 v1.11 change history, version 1.8: Reader, Sorter, Drafter, Checker join the Doer catalogue (the Writer, AIW-D53); decided 11 Oct 2026, AIW-D53).
WriterThe AI Doer that drafts messages and letters for a person to approve; named on 11 Oct 2026 so that Drafter stays the name of the template engine (decided 11 Oct 2026, AIW-D53).
ClockerThe product's time-tracking tool keeps this name (FD-8; decided 11 Oct 2026, AIW-D51).
QualifierThe engine that runs the eligibility assessment from the pack's rules; the same inputs and pack version give the same result (AG-03 v1.4; AG-3-39; catalogue G10).
FinderThe product's search across records that shows only what the asker may see (Doc 1 §8.8, per catalogue D9); its release is Unknown.
ConductorThe engine that runs Doers when something happens (AG-11 v1.11 §3.0).
RecipeA ready-made automation: when this happens, check these things, then do these actions in order (AG-11 v1.11 §3.5). Every persona is specified as a recipe (IMP-10).
Recipe autonomy settingThe "Send automatically / Ask me first / Off" level the firm set for the template messages of one recipe (AG-11-52).
Needs you / Done for youThe staff home screen: the queue of drafts waiting for a person, then the feed of what the Doers did (AG-11 v1.11 §3.13).
Autonomy level · AUTO / APPROVE / OFF · FloorPer action, "Send automatically / Ask me first / Off" (AG-11-51). Permission keyThe product's own name for "this role may do this", written like agent/case:form-approve (SA-06 v3.1; AG-07 v2.7 §10). Named in this document so an approval can be checked against the firm's settings; never a new rule.
